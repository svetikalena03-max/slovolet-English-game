# Словолёт — английские приключения

Игра и тренажёр английского для дошкольников и школьников до 11 класса. Перед уроком можно открыть карточки с правилом, примерами, переводом и озвучиванием; в подходящих темах есть короткие карточки с исключениями. В 3–4 классе добавлен переходный урок с формами глаголов и сборкой предложений. В 5–11 классах восемь заданий идут от разминки через практику к сборке предложения. У младших есть карты приключений. Ошибки сохраняются в разделе «Прогресс» для последующего повторения, а звёзды и текущий урок — в браузере.

## Запуск

В папке проекта выполните `python3 -m http.server 8000` и откройте `http://localhost:8000`.

Для отправки как документа без интернета используйте `Slovolet-offline.html`. Это отдельная копия игры; сохранения браузерной версии в неё не переносятся.

## Публикация

Файлы статического сайта находятся в корне проекта. Пути к картам относительные, поэтому их можно разместить в подпапке, например через GitHub Pages.

## Дальнейшие идеи

- Разговорный тренажёр: прослушать реплику, передать её смысл, ответить по-английски и получить объяснение ошибок. Начать с коротких диалогов, затем добавить запись голоса.
- Режим путешествия: разговорник и перевод фраз в обе стороны.
- Проверка самостоятельного перевода текста, а затем заданий из загруженных файлов. При проверке учитывать несколько правильных формулировок.
