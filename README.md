# Словолёт — английские приключения

Игра и тренажёр английского для дошкольников и школьников до 11 класса. Перед уроком можно открыть карточки с правилом, примерами, переводом и озвучиванием. В уроке восемь заданий; в темах на перевод четыре вопроса с английского на русский и четыре с русского на английский. У младших есть карты приключений, у старших — перевод, времена и сборка предложений. Ошибки сохраняются в разделе «Прогресс» для последующего повторения, а звёзды и текущий урок — в браузере.

## Запуск

В папке проекта выполните `python3 -m http.server 8000` и откройте `http://localhost:8000`.

Для отправки как документа без интернета используйте `Slovolet-offline.html`. Это отдельная копия игры; сохранения браузерной версии в неё не переносятся.

## Публикация

Файлы статического сайта находятся в корне проекта. Пути к картам относительные, поэтому их можно разместить в подпапке, например через GitHub Pages. Пока проект в работе, доступ к исходной онлайн-версии ограничен владельцем.
